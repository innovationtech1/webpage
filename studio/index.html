Publicar gratis en GitHub Pages
  1. Descarga la página (index.html).
  2. En GitHub crea un repositorio nuevo con el nombre del cliente.
  3. Toca Add file → Upload files y sube el archivo.
  4. En Settings → Pages elige la rama main y guarda.
  5. En 1–2 minutos tu página queda en línea.
